# 포커 학습 트레이너

브라우저에서 바로 실행되는 오프라인 포커 학습 도구입니다. 외부 라이브러리 없이 `index.html` 하나로 동작합니다.

## 바로 열기

- **GitHub Pages**: https://hwajungsong951-eng.github.io/poker-trainer/
- 로컬: `index.html`을 더블클릭

## 기능

- 2~5인 테이블, 딜러 버튼 회전, 간단한 AI 상대
- 5장 핸드 평가기 (하이카드 ~ 로열 플러시)
- 몬테카를로 승률 계산 (상대 수 반영)
- 포지션·팟 오즈·타이밍 기반 추천 액션
- 승부 포인트 4가지(임플라이드 오즈, 세미 블러프, 숏스택, 셋 마이닝)
- 유치원생 눈높이 쉬운 설명 + 액션 피드백 + 핸드 요약
- 모바일 세로 화면 지원 (한 화면에서 플레이·설명·액션)

## 참고

- 인터넷 연결 없이 로컬에서 실행 가능
- GitHub Pages에서는 모바일 브라우저로 바로 접속 가능
- 사이드 팟은 계산하지 않습니다.
